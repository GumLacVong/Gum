🤖 Tự động cộng credits khi ngân hàng nhận tiền — Cách làm (15 phút)

Vì sao chưa tự động được? Web bạn đang là web tĩnh, ngân hàng MB không tự báo về web được. Phải qua SePay làm trung gian.

Bước 1 — Đăng ký SePay (miễn phí): Vào sepay.vn → Đăng ký → Liên kết tài khoản MB Bank 212119 - DIEP MINH THUAN
Bước 2 — Tạo Webhook: Trong SePay → Webhook → Thêm URL: https://gum-rho.vercel.app/api/sepay-webhook
Bước 3 — Thêm file API lên Vercel: Trong repo Gum, tạo thư mục api → tạo file sepay-webhook.js với code mình để sẵn ở dưới (copy trong Admin → nút Xem code webhook)
Bước 4 — Test: Chuyển khoản 10.000đ ghi NAP THUAN 10000 → SePay báo về → Web tự đọc nội dung → Cộng 12 credits cho THUAN ngay, không cần bạn bấm gì.

Trong lúc chưa làm SePay: Bạn cứ dùng ô Cộng credits tay ở trên. Ngân hàng báo tiền về điện thoại → bạn vào Admin → nhập tên + credits → bấm Cộng là khách có ngay. 

// File: api/sepay-webhook.js — Copy file này lên repo Gum, thư mục api/
// SePay sẽ gửi POST về đây mỗi khi có tiền vào MB Bank 212119
export default async function handler(req, res){
  if(req.method!=='POST') return res.status(200).json({ok:true});
  const body = req.body || {};
  // SePay gửi: content = "NAP THUAN 10000", transferAmount = 10000
  const content = (body.content || body.description || '').toUpperCase();
  const amount = Number(body.transferAmount || body.amount || 0);
  // Tách tên: NAP THUAN 10000 -> THUAN
  const m = content.match(/NAP\s+([A-Z0-9]+)\s+(\d+)/);
  if(!m) return res.status(200).json({ok:true, skip:'khong dung dinh dang'});
  const username = m[1];
  // Map tiền -> credits: 10000=12, 49000=75, 99000=175, 199000=390
  let credits = 0;
  if(amount===10000) credits=12;
  else if(amount===49000) credits=75;
  else if(amount===99000) credits=175;
  else if(amount===199000) credits=390;
  else credits = Math.floor(amount/1000);
  // TODO: Cộng credits cho username vào Database (Supabase / Vercel KV)
  // Sau khi làm Database ở Bước 2, thay dòng này bằng lệnh cộng thật
  console.log('CONG CREDITS', username, credits);
  return res.status(200).json({ok:true, username, credits});
}
